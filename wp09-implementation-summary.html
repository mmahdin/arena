Implementation summary

WP-09 — Retrieval Service

Deterministic, read-only recall of prior memory for the Theia AI Core, implemented against Contract Pack v1.2 and the Final Architecture Document. Temporal, thread, entity, anaphora and hybrid strategies share one pinned configuration from the Knowledge Bundle. No runtime cutover, no hard delete, no new external service.

Implemented features

Temporal exact recall

Half-open local-time windows parsed in the persisted user zone ("today", "last Tuesday", "3 days ago"). Window messages are returned verbatim; an empty window reports nothing found and is never filled by a semantically similar memory.

Thread, entity and anaphora lookup

Memory linked to the focus or top active thread, records whose stored entity role matches a role the user named, and recent emotion-tagged items for references like "the same feeling again".

Hybrid ranking

Bounded lexical candidates are cosine-reranked in Go against stored vectors: 0.50 similarity, 0.20 recency (21-day half-life), 0.15 importance, 0.15 thread match, compared to the bundle's minimum score.

Missing-embedding honesty

A candidate without a comparable vector gains no similarity. Absent vectors, foreign models and dimension mismatches contribute zero rather than a fabricated relevance score.

Owner isolation and soft delete

Every read is scoped by the server-resolved user id first and re-checked in Go. Soft-deleted rows and their parents are hidden by visibility predicates; nothing is ever purged.

Degradation policy

Ownership and validation errors abort; infrastructure failures return partial items with a degraded flag. A total outage returns a typed error, never an empty result presented as confident recall.

Integration requirements

  • Composition wiring. Construct the retriever with composition.NewRetriever and inject it as WP-05's Dependencies.Retriever. Nothing in the live turn path is replaced by this patch.
  • Shared bundle registry. Pass the same WP-03 registry that pins per-turn bundles; config/retrieval.yaml and config/budgets.yaml must exist and validate, or retrieval fails closed.
  • Embedding model identity. Configure the exact model id and dimensions already stored in dbo.ai_embeddings. A mismatch is ignored rather than mis-scored, so it degrades recall silently.
  • User time zone. Windows are computed from ai_user_state.tz; users without state default to UTC.
  • WP-05 precondition. Enabling the retriever for real turns needs a coordinated orchestrator change to forward admission time and text, which this patch deliberately does not make.

Unresolved issues

  • No live SQL Server was available. The six WP-09 integration tests compile and skip without WELLBEING_INTEGRATION=true; the SQL has not been executed against SQL Server 2022 in this environment.
  • Novelty filter not applied. Dropping memory already present in recent messages needs the assembler's history; duplicating that read here would split WP-08's authority.
  • Person aliases unresolved. Anaphora resolution to a named person is still open in v1.2, so names are never promoted to entity roles.
  • Linear vector search. Cosine reranking scans a bounded candidate pool with no ANN index; this must not be presented as millisecond vector search at scale.
  • Thresholds unvalidated. Only a synthetic bundle was available; the minimum-score floor has not been tuned against real recall quality.
  • Pre-existing failure. One orchestrator replay test fails on the base commit with WP-09 reverted; it is unrelated to this work.
