# تیا / Theia — identity and design system

Theia is the Greek Titaness of sight and shining light. The product borrows the **idea**
(seeing more clearly, light arriving through an opening), never the props: no statues, temples,
columns, laurels, eyes, suns, moons or stars. Everything is drawn, quiet and contemporary.

Persian-first, RTL-native, mobile-first inside a 430px shell.

---

## 1. Materials

| token | value | role |
| --- | --- | --- |
| `--ink` | `#100f0c` | night surfaces (welcome, interstitials, voice, home, chat, letters) |
| `--ink-raised` / `--ink-card` | `#17150f` / `#1d1a14` | cards, bubbles, sheets on ink |
| `--paper` | `#f2ede3` | parchment surfaces (questions, readiness, settings) |
| `--paper-raised` | `#ebe3d5` | raised parchment |
| `--sand` / `--sand-deep` | `#e6dac6` / `#dbccb2` | the approach (conversation style) screen |
| `--ember` | `#de9558` | the light: accents, seals, active marks |
| `--ember-deep` | `#a0532c` | ember that must pass contrast on paper |
| `--ember-soft` | `#f0c8a2` | warm secondary text on ink |
| `--verdigris` | `#7e9a8c` | rare, quiet confirmation |
| `--glow` | `#ffe9cc` | light bloom |

Surfaces are flat, never gradient-filled cards. The only gradients are light itself
(a soft bloom behind a source) and the home sky. Shadows are almost absent; separation comes
from value and hairlines (`--line`, `--ink-line`, `--paper-line`).

Legacy aliases `--light`, `--dark`, `--beige` stay because the shell transition
(`screenSurface.js`, `.app-shell[data-screen-surface]`) is built on them.

## 2. Type

- **Interface:** Estedad Variable (`--font-ui`), weights 380–650. Persian UI copy is short and spoken.
- **Brand / display:** Noto Naskh Arabic (`--font-display`) for greetings, headings, letter bodies and the wordmark.
- Scale: `--display-xl` clamp(30→36), `--display-lg` clamp(25→30), `--display-md` 23, body 15, small 12.5.
- Headings use `text-wrap: balance`; body copy is capped at 33ch so lines stay readable.
- Numerals are Persian (`toLocaleString('fa-IR')`), never Latin, in user-facing strings.

## 3. Marks

- **`TheiaMark`** — a tapered brush ring with a gap, plus one ember spark. The ring is generated by
  `ringPath()`: the stroke weight breathes along the arc and the radius wobbles by ~1%, so it always
  looks drawn, never geometric.
- **`TheiaWordmark`** — «تیا» in Naskh with an ember dot; `tone="paper" | "ink"`.
- **`Aperture`** — the home interaction: two rings opening toward a bloom, dust, and a spark.
  It is the only large interactive symbol in the product; the sentence of invitation sits inside it.
- **App icon** — the same ring + spark on ink (`public/assets/theia-icon.svg`, rasterised 512/192/180).
  `public/favicon.svg` is the same art; `public/manifest.webmanifest` carries the install metadata.

## 4. Illustration language

One vocabulary, varied compositions (`LightStudy`, 360×400, scenes: `welcome`, `simple`, `deeper`,
`know`, `almost`, `ready`, `privacy`, `checkins`, `horizon`):

- a light source **with an edge** — haze, bloom, disc, rim, never a formless flare;
- hand-drawn horizon lines that thin toward the light;
- dust particles with decreasing opacity;
- a small **faceless presence** (the person), sometimes walking, sometimes reflected, never a mascot.

Recurring rhythm across onboarding: light high and far (welcome) → a path with a small light at its end
(simple) → veils in front of the light (deeper) → the light in water, never mirrored whole (know) →
the opening as large as the world (almost) → dawn over a dune (ready). Information screens use the
same grammar without a figure: a cupped contour around a held light (privacy), three fading arcs
(checkins), an open horizon (horizon/about).

Avoided: radial-only glow orbs, concentric target rings, symmetric "wifi" arcs, tight snail spirals,
big wax seals with curved crops, decorative blobs, stock photography, repeated identical panels.

## 5. Components

`StatusBar`, `BackButton`, `PrimaryButton`, `PageHeader`, `PagerDots`, `ChoiceButton`, `BottomSheet`
(`src/components/UI.jsx`) and the brand primitives (`src/components/Brand.jsx`).

- **Primary action** is a full-width ink (or parchment on ink) button with 56px height, 12px radius,
  and a single ember dot before the label. One primary action per screen; everything secondary is a
  quiet text button.
- **ChoiceButton** is a hairline card with a drawn tick; selected state raises the border and adds an
  ember dot — no filled pills, no gradients.
- **BottomSheet** is a native `<dialog>`: focus is returned to the trigger on close, Escape and backdrop
  clicks close it, and it inherits the screen's theme variables.
- **Toggles** (privacy) are 40×24 hairlines whose knob travels with `justify-content`, so the direction
  is correct in RTL without physical transforms.
- **Loading** is `TheiaLoader`: one breathing light. **Empty** is `QuietVignette`: the aperture waiting,
  never a sad icon. **Errors** are text + one retry, never red blocks.
- **Letters** use `LetterSymbol` (a drawn sheet with an ember seal) and a parchment reading surface at
  `--paper` with a 21px Naskh body and 2.05-2.15 line height.

## 6. Motion

- Screen entry: 260ms opacity `.96 → 1` + 7px rise; no white flash (`screenSurfaceForRoute` decides the
  surface colour, and the transition element paints it).
- Messages: 320/420ms rise. Tools: height + opacity. Voice carousel: 460ms snap.
- All of it is disabled under `prefers-reduced-motion: reduce`; the age wheel stops tilting and the
  approach replies stop sliding.

## 7. Copy rules

Short, warm, spoken Persian. «تو» not «شما». No claims about outcomes, no invented credentials,
testimonials, research or clinicians. Privacy copy states exactly what is stored and why. Crisis
direction is the honest one: اورژانس اجتماعی ۱۲۳ or a trusted person. Negative feelings are never
drawn as ugly things — the light simply moves.

## 8. Extending

1. New surface? Add it to `src/features/appearance/screenSurface.js` so the shell transition paints it.
2. New illustration? Compose it from `Light`, `Dust`, `Figure`, horizon strokes and `Grain` in
   `Brand.jsx`; keep the palette constants (`NIGHT`, `PAPER`, `SAND`, `DAWN`).
3. New screen? Start from `.app-screen` + `theme-*`, use `StatusBar`, `PageHeader`, one primary action.
4. Never introduce a second icon language: `lucide-react` at 1.5–1.6 stroke is the only icon set, and
   icons are reserved for actions, not decoration.
