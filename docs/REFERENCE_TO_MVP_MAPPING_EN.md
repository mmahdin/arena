# Reference-to-MVP Design Map — Exactly What to Borrow and What to Reject

This file is **the bridge between the 61 The Path screenshots and our own five-feature MVP**. It prevents the design tool from copying a visually polished but strategically different product. Image numbers correspond to the original JPGs (descending `61 → 1`). Every indicated `photo_N` is available in the `screens/` folder; see the HTML viewer for visual browsing.

## Guiding principle

Use **principles and reusable visual systems**, not The Path's product rules. The source is a therapy-session-oriented product using named portrait guides and fixed session lengths. Our product is a Persian **AI conversation companion** supporting persistent multiple chats, behavior-based communication styles, user-controlled memory, a reflective profile, and self-discovery assessments. These are not interchangeable product flows.

## Visual sequence to preserve in spirit

```text
Refined atmospheric welcome
    ↓
Quiet, high-legibility one-question onboarding
    ↓
Optional light reflective pause
    ↓
Bold, distinctive communication-style selection
    ↓
Calm personalized home / independent chat threads
    ↓
Intimate, simple, continuous AI chat
    ↓
User-controlled self-understanding and self-discovery
```

## Screen category decisions

### 1. Dark cinematic introductions: 61–58

Borrow the **contrast between quiet black stage, a few olive symbolic elements, and a floating pale narrative card**. A dark cinematic intro can be beautiful, but keep it short. The current product value is not 'therapy session on demand'; write our own accurate companionship promise.

### 2. Light onboarding and quiet reflections: 57–39

Borrow the reusable **QuestionShell**: understated header, progress, strong title, small choice set, a single anchored CTA, huge breathing room. Alternate with occasional **ReflectionInterlude** to avoid a transactional form feel. Keep it much shorter than the full source journey. Do not use the source's emotionally specific sample reflections as actual user data.

### 3. Emotional / numerical interstitials: 49, 38, 36, 33, 30, 29

The real design strength is **a rare dramatic pause** with soft, layered gradients, huge type and a white pill CTA. Use a few such moments with original messaging. Percentages, testimonials, quotes and claims in the reference are not authorized proof for our product.

### 4. The AI guide gallery: 21–10

Borrow consistency: **one premium large-format card with dramatic visual depth**, one name, 1–2 behavioral traits, short useful description and selection action. Our five communication styles should **not be a cast of portrait people** by default. Use abstract symbolic artworks, material-like shapes, subtle color families and unique but consistent layouts. Replace the source's voice preview with an even more useful **same-message response preview**.

### 5. Dark chat and returning home: 9–1

Borrow immersive dark chat atmosphere, clean type and the clear distinction between first-message screen and active conversation. The source's timer, duration selector and guide biography are not requirements. Convert the home 'focus areas' into a list of chat threads. Create profile, memory and assessment destinations that the reference set does not show, based on our own product brief.

## Where reference coverage ends

The supplied screenshots **do not establish** the following desired features: multiple independent chats, selective semantic cross-chat memory, user-controlled memories, explicit AI tone switching within an active thread, same-prompt response comparison, a self-understanding profile, a genuine assessment library, assessment scoring, and editable personal insight provenance. Treat all of these as new, original MVP product design. Use The Path only for the overarching visual language.
